## 自动驾驶与导航

### 1. [FastVLA: Task-Conditioned and Temporally Adaptive Visual Token Compression for Efficient Vision-Language-Action Models](https://arxiv.org/abs/2610.22146)

- **作者与时间：** 论文团队；v1 2026-10-15 17:19 UTC。
- **问题与创新：** VLA 的视觉 token 压缩若固定比例，会在关键动作阶段丢掉细节；FastVLA 让压缩率由任务和时间上下文共同决定。
- **机制：** 任务条件路由器预测 token 重要性，时间自适应模块在动作变化快或接触临界阶段保留更多 token，其他阶段进行更激进合并；训练目标同时约束动作质量和计算预算。
- **实验与关键结果：** 摘要报告在机器人操作基准上以更少视觉 token 保持或提升成功率，并降低推理成本；具体收益需以论文完整表格核验。**关注价值／局限：** 直接把视觉预算变成策略状态，适合端侧部署；重要性误判可能在短暂风险窗口造成不可逆信息损失，尚需真实时延和长尾审计。

### 2. [FALCON: FPGA-Accelerated Latency-Certifiable Occupancy Networks for Camera-Based Autonomous Driving](https://arxiv.org/abs/2610.22143)

- **作者与时间：** 论文团队；v1 2026-10-15 17:17 UTC。
- **问题与创新：** 摄像头占据网络通常追求平均吞吐，却难给出稳定的最坏时延；FALCON 将占据预测结构与 FPGA 数据流协同设计。
- **机制：** 以可流水化的稀疏/定点算子组织多视角特征和占据解码，并用硬件调度约束推理路径，使延迟上界可估计而非只看平均值。
- **实验与关键结果：** 摘要强调在摄像头自动驾驶占据任务上实现低延迟、可证明的时延曲线，同时保持竞争力精度。**关注价值／局限：** 把实时性从部署后优化提升为模型—硬件接口；FPGA 设计迁移到不同分辨率、传感器和软件栈的成本，以及精度—资源—上界的完整 Pareto 曲线仍需核查。

## 机器人／具身智能

### 3. [Perceive, Predict, and Plan: a Unified World Action Model for Egocentric Dexterous Manipulation](https://arxiv.org/abs/2610.22363)

- **作者与时间：** 论文团队；v1 2026-10-15 17:59 UTC。
- **问题与创新：** 灵巧操作的感知、未来预测和动作规划往往由不一致的模块承担，导致预测无法真正约束动作。该工作统一三者为 world action model。
- **机制：** 从第一视角观测编码场景与手部状态，预测动作条件未来，再用规划头在预测空间搜索可执行动作；训练同时使用视觉未来和动作结果监督。
- **实验与关键结果：** 摘要报告在灵巧操作任务上较分离式感知—策略基线取得更好的预测和执行表现。**关注价值／局限：** 统一接口便于把世界模型用于动作选择；第一视角遮挡、长时误差累积和真实接触动力学仍可能令 rollout 失真。

### 4. [Value as Memory: Online Value-Guided Post-training for General Robot Policies](https://arxiv.org/abs/2610.22368)

- **作者与时间：** Wenye Yu、Yijin Chen、Kaiyi Xiong 等；v1 2026-10-15 17:59 UTC。
- **问题与创新：** 部分可观测长任务让单帧动作歧义，离线后训练又不能及时吸收真机经验。VaM 把近期 value prediction 缓存为任务进度记忆，并支持在线自主学习。
- **机制：** 离线演示、离策略干预和 on-policy rollout 先用于 warm-up，再在稀疏奖励下并行采集与更新；value cache 作为动作条件输入。
- **实验与关键结果：** 可变形和接触密集任务中，value cache 平均成功率绝对提升 **29.4%**，在线学习比匹配离线训练高 **32.8%**；同梯度预算下 policy iteration 为 **8×**，单步时间低逾 **2×**。**关注价值／局限：** 让进度估计成为可复用控制状态；value 漂移、错误干预和在线探索的碰撞成本需独立报告。

### 5. [T2-z: Test-Time Optimization of Environment Latents for Robotic World Models](https://arxiv.org/abs/2610.22364)

- **作者与时间：** Chenyuan Zhou、Yining Hong、Huang Huang 等；v1 2026-10-15 17:59 UTC。
- **问题与创新：** 摩擦、质量和人为规则等环境变量不可直接观察，世界模型在新环境中会失配。T2-z 在测试时优化紧凑环境 latent。
- **机制：** 训练交替固定 latent 学通用动力学、固定模型优化 latent；测试时冻结世界模型，只从一次或数次交互更新新环境 latent，再用于预测和规划。
- **实验与关键结果：** 7 个仿真设置和 4 个真机任务中，物体预测误差从 **15.20 降至 7.00**，动作成功率从 **33.73% 升至 72.96%**；摘要称单条交互轨迹即可推断环境因素。**关注价值／局限：** 以小状态接口连接环境适配和规划；测试时试探动作可能不安全，latent 的可解释性和跨任务稳定性仍需验证。

## 交叉方向：空间表示与多智能体

### 6. [Velox: Spatial Memory Makes World Models Efficient](https://arxiv.org/abs/2610.22311)

- **作者与时间：** 论文团队；v1 2026-10-15 17:56 UTC。
- **问题与创新：** 视频世界模型反复处理冗余历史，长时预测的计算和记忆成本快速增长。Velox 用空间记忆替代无差别时间堆叠。
- **机制：** 将历史观测压缩为带空间索引的持久状态，只对新视角或发生变化的区域更新；预测器从该记忆读取动作相关上下文，而非重算全部帧。
- **实验与关键结果：** 摘要报告在世界模型预测上显著减少历史计算并保持预测质量。**关注价值／局限：** 与长期地图和任务条件记忆有直接接口；动态遮挡、错误更新和多视角坐标漂移决定其能否用于长期自治。

### 7. [Learning Self-Orchestration in Decentralized Agent Swarms](https://arxiv.org/abs/2610.22322)

- **作者与时间：** 论文团队；v1 2026-10-15 17:51 UTC。
- **问题与创新：** 去中心化多机器人/多 Agent 系统通常依赖预设编排规则，难以在通信受限和任务变化时重组。该工作学习 Agent 自主分工与通信时机。
- **机制：** 每个 Agent 根据局部观测、任务进度和邻居消息选择角色、动作及是否通信，训练目标同时考虑任务回报、通信成本和冲突避免。
- **实验与关键结果：** 摘要称在协作任务中比固定编排提高适应性，并在通信预算受限时保持性能。**关注价值／局限：** 将编排本身纳入策略可减少中央控制依赖；消息误解、故障传播、可验证性和真实无线链路延迟仍是部署门槛。

## 趋势总结

本期回溯显示三条线索相互收敛：视觉/历史信息开始按任务和空间重要性分配计算预算；世界模型从离线预测器变成可在测试时适配环境、服务动作选择的状态接口；多 Agent 编排则把角色、通信和资源约束写进策略。共同风险是压缩、latent 适配或自治协作一旦错误，可能在闭环中放大而不是平均化，后续应优先补充时延上界、失败归因、回退和真实硬件证据。
