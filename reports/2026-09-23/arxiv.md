## 自动驾驶

### 1. DreamStream: Towards Policy-Oriented Generative Simulation for End-to-End Driving

- **论文／作者／时间**：[arXiv:2609.26792](https://arxiv.org/abs/2609.26792)；Ziyang Leng、Sicheng Mo、Seth Z. Zhao、Haoyuan Cai、Yu Zeng、Rowan McAllister、Bolei Zhou。v1：2026-09-22 17:59:31 UTC；页面注明 CoRL 2026 接收。
- **问题**：仿真画面像真实照片，不代表保留了驾驶策略决策所需的布局、动态目标和时序线索；视觉域差异可能让闭环测试实际测到感知损坏。
- **创新与机制**：以仿真状态为基础构建自回归视频模型，用交通布局引导从大规模预训练视频模型蒸馏，在改变外观时保持任务相关结构。另提出 FDπ，在公开端到端策略的场景上下文特征空间衡量真实与仿真分布差异，避免仅用 FID 判断生成质量。
- **实验与结果**：作者报告在 FDπ 指标下，相比最强既有闭环仿真器，nuScenes 与 NAVSIM 分别改善 1.6 倍、4.7 倍；这不是驾驶成功率倍增。基于该系统构建 Navhard-CL，将 NAVSIM 扩展为带对抗驾驶和天气变化的交互环境，揭示评分器偏差与失败后恢复不足。
- **关注价值**：把“生成得好看”转成“是否保留策略可观测信息”，对世界模型用于评测的有效性很关键。
- **局限／跟进**：特征指标依赖选取的公开策略，仍应验证对未参与定义指标的架构是否成立；仿真里的恢复缺陷也需真实闭环或独立仿真器交叉确认。

### 2. NavSafe-∞: Benchmarking Closed-Loop Driving Safety in Photorealistic Environments

- **论文／作者／时间**：[arXiv:2609.26618](https://arxiv.org/abs/2609.26618)；Yuxin Bao、Hongwei Ruan、Luobin Wang、Seth Z. Zhao、Ziyang Leng、Zihan Zhang、Yu Zeng、Rowan McAllister、Henrik Christensen、Bolei Zhou。v1：2026-09-22 15:51:07 UTC。
- **问题**：开环得分不能检验误差累积、失败恢复和与其他道路参与者的安全交互；优化自车前进的奖励也可能牺牲安全余量。
- **创新与机制**：将 280 个场景组织为 28 类事件，并为各类事件明确成功、失败条件。评测输出按交通碰撞、弱势道路使用者碰撞、交通违法、交通事件四类分解，便于把总分变成可诊断的能力缺口。
- **实验与结果**：评测 20 个端到端策略，发现开环进步不能可靠迁移为闭环安全。示范扰动主要在闭环状态仍接近扰动训练分布时有效；开环 RL 微调会通过牺牲安全距离换取前进收益，闭环反馈进一步放大错误。摘要未给统一改善百分比，本期不补造。
- **关注价值**：为“后训练提升”提供反向检验：应同步观察风险类别和恢复行为，而非只看最终排行榜。
- **局限／跟进**：280 个场景不代表全部长尾分布；摘要表述工具箱将开源，不能写成已全部可用。应跟进公开版本、事件覆盖和跨仿真器一致性。

## 机器人／具身智能

### 3. Imperfection for Precision: Upcycling Imperfect Data for High-Precision Robotic Manipulation

- **论文／作者／时间**：[arXiv:2609.26672](https://arxiv.org/abs/2609.26672)；Hao Wei、Yang Liu、Chao Tang、Shengbao Li、Jiangtao Chen、Jinxuan Zhu、Jiaheng Wang、Hong Yin、Zhaofeng Cao、Tingguang Li。v1：2026-09-22 16:32:24 UTC。
- **问题**：高精度操作依赖昂贵的任务专属高质量遥操作数据；本任务低精度数据和其他任务的高精度数据往往被弃用，直接混合又可能互相干扰。
- **创新与机制**：ε4P 沿 flow-matching 的噪声时间分配不同来源数据。高噪声阶段用目标任务的低精度轨迹保留任务语义，低噪声阶段用任务不匹配但动作精细的数据传递局部控制精度。创新点在监督信号何时进入生成过程，而不仅是增加样本数。
- **实验与结果**：真实机器人同时测试亚毫米高精度任务和粗粒度任务。加入不完美数据，策略表现最高提升 **31.7 个百分点**；等量替代任务专属高质量数据时，平均仅下降 **4.2 个百分点**。两个数字分别对应增强和替代设置，不可合并为同一个收益。
- **关注价值**：对拥有混杂历史轨迹、又缺目标任务高精度示范的团队，提供比一刀切数据清洗更细的复用路径。
- **局限／跟进**：最高收益不是平均收益；需核查任务间动作兼容性、噪声分界的敏感性，以及接触动力学不同导致的负迁移。

### 4. RouteRLT: Learning When and Which RL Specialist Should Control a Vision-Language-Action Policy

- **论文／作者／时间**：[arXiv:2609.26467](https://arxiv.org/abs/2609.26467)；Chongyu Zhu、Jaden Hinds、Hyegang Kim、Juan Sebastian Rojas、Ramy Elmallah、Chi-Guhn Lee。v1：2026-09-22 14:15:28 UTC；页面注明 IROS 2026 IARL workshop 接收。
- **问题**：通用 VLA 能处理多数操作，但抓取线缆、端口插入等精度关键阶段需要专门控制；统一 RL 微调未必保留原有泛化和恢复能力。
- **创新与机制**：学习何时交接、交给哪一个单阶段 RL 专家。阶段选择器判断活动控制器，稳定器抑制短时切换抖动，动作边界管理器处理不同策略动作块之间的交接，因此路由是控制接口的一部分。
- **实验与结果**：LIBERO 多物体抓放中，学习路由优于基础 VLA，并达到使用特权阶段边界的路由效果，部署无需这些边界。真实线缆拾取和插接实验展示两个专家的自动路由，但采用与操作员对齐的交接协议。摘要未给成功率数值。
- **关注价值**：把 RL 的训练预算集中在少数精度瓶颈，同时尽可能保留通用策略的覆盖面。
- **局限／跟进**：真实交接协议是重要条件，不能描述成任意任务下完全无人值守。应进一步比较切换延迟、错误路由率及专家数量增加后的标注和维护成本。

### 5. Generalizing Manipulation Skills with a Local Coding Agent

- **论文／作者／时间**：[arXiv:2609.26499](https://arxiv.org/abs/2609.26499)；Raman Talwar、Elias Nijs、Andreas Verleysen、Francis wyffels；前两位共同贡献。v1：2026-09-22 14:32:17 UTC。
- **问题**：固定动作接口或专门训练的策略遇到新任务变化时，往往需要新增人工代码或采集数据；本地开放权重模型是否能通过写代码实现一次性泛化？
- **创新与机制**：在单工作站上让 Qwen3.8-27B VLM 运行于 coding-agent harness，自行编写、执行和调试控制代码。底层服务提供运动学、安全限制及经典视觉能力，代码生成负责组合技能，机器人为 UR3e。
- **实验与结果**：9 个儿童玩具操作任务覆盖颜色、尺寸、形状和任务变化，每任务 5 次，共 **30/45 次成功泛化**；耗时 **3.4–67.5 分钟**。成功后要求重做任务，耗时减少约 **50%**，属于重复任务的执行改善，不能直接推为模型权重持续学习。
- **关注价值**：连接软件 Agent 与机器人技能复用，给出完整本地运行路径及可量化的时间代价。
- **局限／跟进**：样本规模小且任务受限，分钟级耗时不适合快速反馈控制；安全依赖底层服务边界。需跟进未知物体、失败恢复和重复执行时复用内容的独立消融。

## 交叉方向：SLAM／3D／长期自治

### 6. Dr-LiSA: Direct Radar-Lidar Scan Alignment for SE(3) Localization

- **论文／作者／时间**：[arXiv:2609.26423](https://arxiv.org/abs/2609.26423)；Alex Zhang、Daniil Lisus、Cedric Le Gentil、Timothy D. Barfoot。v1：2026-09-22 13:50:08 UTC；审稿中。
- **问题**：雷达耐恶劣天气，激光地图几何质量高，但两者观测机制不同；既有雷达到激光地图定位常局限于平面 SE(2)，精度也受模态差距限制。
- **创新与机制**：学习从候选位姿下的激光子地图预测二维旋转雷达强度的前向模型，在预测与真实雷达扫描间直接做光度对齐，并优化 SE(3) 位姿。它通过可预测的观测模型连接模态，而非要求原始点云天然可比较。
- **实验与结果**：在超过 **90 km** 道路数据上，平面定位优于既有雷达—激光方法，与先进雷达—雷达定位精度相当。摘要没有给六自由度误差表；“支持 SE(3)”与“六轴精度全部领先”不是同一结论。
- **关注价值**：可在既有高质量激光地图上使用不同传感器定位，为自动驾驶和室外机器人跨天气运行提供路径。
- **局限／跟进**：恶劣天气鲁棒性是动机，尚不能据摘要推断已完成全面雨雪测试；需检查俯仰／高度可观测性、初始化范围和跨雷达设备泛化。

### 7. ArborSplat: Online Semantic Gaussian Splatting SLAM for Orchards

- **论文／作者／时间**：[arXiv:2609.26315](https://arxiv.org/abs/2609.26315)；Alessandro Masini、Matteo Frosi、Mirko Usuelli、Matteo Matteucci。v1：2026-09-22 12:25:10 UTC。
- **问题**：树干、支架、果实等细小结构对果园任务重要，但外观驱动的 3DGS 容易把它们的像素深度归到背景，导致语义映射错误和容量分配不足。
- **创新与机制**：激光里程计负责跟踪，语义直接在高斯地图上优化；利用每个关键帧双目点云估计地面，以类别特定高度带约束语义。在线融合多视角证据，并拒绝与地面或单目深度不一致的标签；类别约束细化为稀缺结构保留高斯容量。
- **实验与结果**：苹果、梨果园覆盖休眠、开花、采收期；12 条完整路线的 ATE 均低于 **0.5 m**。共同的 301 帧片段上，相比 SGS-SLAM 和 GS3LAM，训练视角 mIoU 高 **0.23–0.50**、留出视角高 **0.15–0.36**，速度为 **1.7–7.5 倍**；SemGauss-SLAM 在六个对照片段均显存不足。mIoU 差值是绝对值，不是相对百分比。
- **关注价值**：明确将有限地图容量分配给任务重要结构，使语义质量与在线预算一起进入 SLAM 设计。
- **局限／跟进**：短片段语义比较不能等同整条路线的语义指标；类别高度先验需验证在坡地、其他树形和非果园环境中的适用性。

## 趋势总结

1. **驾驶评测要同时审计观测和反馈**：DreamStream 检验仿真是否保留策略相关证据，NavSafe-∞ 检验得分提升是否转化为闭环安全。生成质量、策略指标、风险分类不能互相替代。
2. **VLA 的精度提升开始依赖“分配”**：ε4P 分配各来源数据在噪声阶段的作用，RouteRLT 分配通用策略和专家的控制权；关键不只是模型规模，也包括监督和动作接口的时间结构。
3. **Agent 可组合性进入物理执行，但吞吐差距清晰**：本地 coding agent 的 30/45 成功率与分钟级耗时应一起阅读；可重用程序值得研究，不能据此宣称实时自治已解决。
4. **地图要对齐传感器，也要保住任务结构**：Dr-LiSA 建立跨模态观测模型，ArborSplat 为稀缺语义结构保留容量。长期自治除了复用地图，还要解释何种观测和语义证据得以保留。
