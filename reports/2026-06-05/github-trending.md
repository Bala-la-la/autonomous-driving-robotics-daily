简短总结
1. 最近 GitHub 热点非常清晰地偏向“AI 系统的基础层”而不是单点模型：文档 ingestion、流式数据、浏览器代理、代码图谱、deep research workflow 都在涨。
2. 社区偏好正在从“酷 demo”转向“可接入企业环境的中间层”：能连数据、连文件、连浏览器、连代码库的项目更吃香。
3. 另一个明显变化是“教程/课程型仓库继续强势”，说明大量开发者仍在补 agent 工程化基础，而不只是追新模型。
4. 本文里 memos/pathway/OpenBB 的日增来自 GitHub Trending 可见信息；markitdown/codegraph 的精确增量主要依据第三方趋势榜快照，因此属于“确认到高增长，精确增量以第三方观测为准”。
