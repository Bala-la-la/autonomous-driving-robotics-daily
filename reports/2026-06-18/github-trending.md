【简短总结】
1. 确认层面看，最近 GitHub 热门并不只偏向“大模型应用”，而是明显分成四条线：agent 工具链、agent 安全、开发基础设施、垂类基础模型。
2. 推断层面看，社区偏好正在从“演示型 AI 项目”转向“能嵌进工作流的系统组件”，比如容器、代码记忆、网络栈、安全扫描和桌面 agent 基础设施。
3. 另一个明显变化是，官方或半官方背书项目更容易形成陡峭涨星曲线，例如 Apple、NVIDIA、Google Research；但开源生态里真正持续吸引人的，仍然是能降低成本、减少 token、缩短部署路径的工具。
