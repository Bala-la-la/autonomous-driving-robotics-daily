## 自动驾驶

### 1. Combining Evasive and Braking Reactions for Safety Reference Models in Automated Vehicles

- **论文／作者／时间**：[arXiv:2609.29738](https://arxiv.org/abs/2609.29738)；Riccardo Donà、Konstantinos Mattas、Biagio Ciuffo。v1：2026-09-24 12:55:28 UTC。
- **问题**：仅用纵向制动刻画谨慎人类驾驶员，会漏掉转向避碰能力，影响自动驾驶场景评测的参照基线。
- **创新与机制**：FSM-H 把纵向缓解和横向躲避放入统一行为框架。PFS 指标描述纵向安全余量消退，CFS-LC 则描述换道冲突强度和可行性；有限状态机从正常驾驶依次升级到制动、必要时转向，并加入感知反应时间与检查邻车道的延迟。贡献是可解释的复合反应逻辑，而非新增一个端到端驾驶策略。
- **实验与关键结果**：在重建的高危险 cut-in 场景中，与仅制动、仅转向策略比较，作者报告可避免碰撞的场景范围扩大，同时保持行为合理性和计算可处理性；摘要未提供扩大比例。
- **关注价值**：有助于识别“测试系统失败”与“参照驾驶员动作集合过窄”这两类评估误差。
- **局限／跟进**：需检查道路空间、邻车道交通及反应延迟参数的敏感性。论文提出的是仿真参照模型，不等同于已获法规认可的安全判据，也未证明真实车队事故率下降。

## 机器人／具身智能

### 2. RAPID: Robot Agentic Programming from Demonstrations

- **论文／作者／时间**：[arXiv:2609.30249](https://arxiv.org/abs/2609.30249)；Yuyao Liu、Jiayuan Mao、David Hsu、Leslie Pack Kaelbling、Tomás Lozano-Pérez。v1：2026-09-24 17:58:21 UTC。
- **问题**：把人类视觉示范变成可泛化机器人程序，既需要动作生成，也需要能检验程序是否正确的任务和环境。
- **创新与机制**：从单个视觉示范自动推断可测试任务规格、动作原语和交互验证环境，再进行生成—执行—验证—修订循环。采用物体中心的关系程序表示：动作原语由轨迹优化实现物体级运动效果，组合关系则在运行时绑定当前几何。它复用的是操作策略结构，不是直接照搬示范中的运动轨迹。
- **实验与关键结果**：仿真覆盖 8 类接触丰富的非抓取操作以及 LIBERO-Pro 抓取任务；真实 Franka 机械臂也测试全部 8 类非抓取任务。作者报告对物体位姿、形状、材质与环境变化的泛化，摘要未列成功率。
- **关注价值**：将演示学习从动作模仿推进为“规格与验证器也由示范产生”，适合关注少样本操作和可复用程序的人群。
- **局限／跟进**：规格、验证环境与策略若共享误解，可能形成自洽但错误的循环；应跟进真实接触模型误差、程序合成预算及示范歧义。

### 3. Rolling-WAM: World Action Models with Rolling Imagination

- **论文／作者／时间**：[arXiv:2609.30247](https://arxiv.org/abs/2609.30247)；Yinghua Zhou、Junjie Ye、Yiqi Zhao、Hao Dong 等 11 位作者。v1：2026-09-24 17:58:03 UTC。
- **问题**：每次重规划都完整去噪整段未来视频和动作，会延迟动作更新，削弱闭环响应。
- **创新与机制**：维护一组噪声程度交错的视频—动作块，以滑动窗口跨重规划周期分摊联合去噪。临近执行的块彻底去噪，较远未来只部分细化；新相机观测到来后窗口前移，保留的未来块继续计算。这样既保留跨块视觉动作上下文，又避免每轮从头生成整个预测范围。
- **实验与关键结果**：在 LIBERO、RoboTwin 和真实 Unitree G1 人形机器人评测；作者报告保持有竞争力的操作表现，相对标准联合 WAM 获得 **4.5 倍稳态重规划加速**。
- **关注价值**：与上期 LiMA 的异步路线形成互补，说明世界模型部署可以重排计算时间，而不只压缩模型。
- **局限／跟进**：4.5 倍是稳态重规划倍率，不是整任务完成速度或启动延迟；需关注突发扰动下保留未来块何时失效、是否需要重新初始化，以及不同硬件上的端到端响应。

### 4. Coding Agents for Generalized Task and Motion Planning Problems

- **论文／作者／时间**：[arXiv:2609.30233](https://arxiv.org/abs/2609.30233)；Matteo Merler、Bowen Li、Josh Roy、Yichao Liang、Qianwei Wang、Yixuan Huang、Tom Silver。v1：2026-09-24 17:53:35 UTC。
- **问题**：离散任务决策与几何、运动学和动力学约束耦合，跨实例复用规划经验通常需要大量专门工程。
- **创新与机制**：给 coding agent 任务描述、仿真器访问权和固定程序合成预算，由其自主选择交互、调试物理模型并修订策略；完成后冻结程序，在未见实例上测试。明确分开昂贵的程序生成阶段与可重复调用的实例求解阶段。
- **实验与关键结果**：在 KinDER、PDDLStream 的 28 个仿真环境测试三种 agent 配置，合计 980 个程序、每个 100 个留出实例，共 98,000 回合。在有手工规划器的 16 个环境上，各 agent 配置平均成功率为 **56%–95%**，规划器为 **47%**；随物体数增加，生成程序仍保持更高成功率，单实例平均计算量低一个数量级。
- **关注价值**：提供了较大规模、程序冻结后的泛化基线，避免把每道题临时调用大模型与可复用求解器混为一谈。
- **局限／跟进**：上述 16 个环境的成功率不能外推为全部 28 个环境；单实例成本不包含前期合成预算。当前证据来自仿真，应跟进部分可观测、感知误差及真实机器人执行。

## 交叉方向：动态导航与三维感知

### 5. UCON: Uncertainty-aware Navigation with Historical Re-association in Dynamic Environments

- **论文／作者／时间**：[arXiv:2609.29419](https://arxiv.org/abs/2609.29419)；Bing Sun、Yue Lin、Yongsheng Yuan、Yang Liu、Dong Wang、Huchuan Lu。v1：2026-09-24 11:41:24 UTC。
- **问题**：动态目标身份切换破坏运动估计，而感知协方差又常不能一致地进入轨迹优化。
- **创新与机制**：用历史点云片段做点级重新关联，恢复丢失目标并保持身份连续；Kalman 滤波提供各向异性的运动状态和协方差传播。随后将预测状态及协方差转成不确定性扇区，作为可微代价接入轨迹优化，将感知不确定性直接连接到避障决策。
- **实验与关键结果**：作者报告仿真和真实实验均改善感知稳定性与动态导航鲁棒性，并保持较高计算效率；摘要未列具体成功率、延迟或算力配置。版本备注为 IROS 2026 接收。
- **关注价值**：历史信息不仅服务地图重用，也服务动态目标身份连续性；安全距离可依据方向相关不确定性调整。
- **局限／跟进**：代价项并不自动构成硬安全保证；需检查长遮挡、急转向下的协方差校准与错误重关联。摘要称代码“将开源”，不能据此写成已经发布。

### 6. M3GD: Multi-Modal Multi-View Geometric Diffusion for Camera--LiDAR Novel View Synthesis

- **论文／作者／时间**：[arXiv:2609.30056](https://arxiv.org/abs/2609.30056)；Yang Zhou、Jiuhong Xiao、Shizhao Ye、Long Quang、Carlos Nieto-Granda、Giuseppe Loianno。v1：2026-09-24 16:14:00 UTC。
- **问题**：机器人新视角生成需要外观和公制三维结构，仅图像生成容易忽略已有激光几何证据。
- **创新与机制**：利用独立预训练且冻结的图像与点云模型在相机投影后共享的空间结构，把显式几何统计和点云描述子组成对齐图像潜网格的特征包；轻量残差适配器将其注入多视图 flow-matching 生成器，保留原潜空间、解码器和训练目标，无需另行预训练跨模态翻译器。
- **实验与关键结果**：GrandTour 数据集上，目标视角 RGB 和深度生成优于同骨干的纯图像版本；消融将收益定位到像素对齐 LiDAR 内容，目标视角 LiDAR 充当连接请求视角与源观测的几何查询。地面机器人展示了真实运行，Euler 积分步数控制质量与成本；摘要未提供具体指标差值。
- **关注价值**：为驾驶和移动机器人提供复用已有预训练模型的几何条件化接口，便于区分模态信息增益与骨干扩容收益。
- **局限／跟进**：目标视角几何查询的获得成本必须纳入比较；不能解读为仅凭图像生成任意未知几何，也不能把合成质量提升直接等同于 SLAM 定位提升。

## 趋势总结

- **安全参照与安全控制要分开评价**：FSM-H 改善参照驾驶员动作集合，UCON 改善不确定性到规划的传递；两者均不自动给出事故率或硬安全证书。
- **机器人程序复用开始覆盖验证资产**：RAPID 自动构造规格与验证环境，广义 TAMP 研究冻结程序后测试大规模留出实例；应同时报告合成成本、验证器可靠性和部署成本。
- **实时世界模型重视计算的时间分配**：继异步双系统后，Rolling-WAM 在窗口内保留未完成未来；平均吞吐之外，突发扰动响应和冷启动成本更值得跟进。
- **空间接口仍需真实观测约束**：UCON 保留身份与协方差，M3GD 保留像素对齐几何；“历史更多”“生成更好”必须落到任务特定的可验证收益。
