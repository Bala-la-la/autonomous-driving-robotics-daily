【简短总结】
1. 最近 GitHub 热门项目最明显的趋势，是 agent 生态在快速分层：上层是 agent-native 应用和 ADE，中层是 design/spec 规范，下层是 repo memory、文档解析、GUI 执行层和代码知识基础设施。
2. 社区偏好也比前一阶段更成熟。高增长项目不再只偏“模型封装壳”，而是更偏能接真实代码库、真实文档、真实网页和真实设计系统的基础设施型仓库。
3. 另一个值得注意的变化是，真实世界机器人与长期工程项目仍然有稳定吸引力。openpilot 能和一众 agent 仓库同时上榜，说明社区并没有完全脱离物理世界与系统工程。
