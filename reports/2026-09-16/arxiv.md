## 自动驾驶与安全

1. [Proactive Safety Filtering for Autonomous Driving with Video World Models](https://arxiv.org/abs/2609.15988)

   - **问题与机制**：把视频世界模型用于驾驶动作的事前安全检查：对候选动作生成未来观测或风险线索，再在执行前做风险过滤，而不是只在碰撞后用失败样本训练。论文强调风险向量与动作选择之间的可验证接口。
   - **实验与关注价值**：在自动驾驶安全场景上比较直接策略与带世界模型过滤的策略，目标是降低危险动作并保留可行性。价值在于把“想象未来”放在控制回路的前置审计位置。
   - **局限**：世界模型误差、预测时延和长尾交通参与者会直接影响过滤器；离线或模拟安全提升不能等同真实道路安全保证。

2. [Compound Robustness in Autonomous Driving: Benchmarking Compositional Perception Failures](https://arxiv.org/abs/2609.15921)

   - **问题与机制**：单一遮挡、天气或传感器噪声的鲁棒性分数，不能代表多个扰动同时出现时的系统行为。论文构造组合式感知失效评测，观察不同缺陷之间的非线性叠加和级联影响。
   - **实验与关注价值**：在自动驾驶感知任务上比较单因素与组合扰动下的性能变化，并分析模型是否能保持场景理解。它提醒 benchmark 需要测试“复合退化”，而不是把各项鲁棒性简单平均。
   - **局限**：组合扰动的真实发生频率、相关性和传感器物理逼真度仍需道路数据校准；benchmark 结果也不自动给出闭环控制风险。

## 机器人学习与具身记忆

3. [MessyMem: Learning Episodic Memory from Real-World Robot Interaction](https://arxiv.org/abs/2609.15870)

   - **问题与机制**：真实机器人日志混合了观察、动作、反馈、失败、重复尝试和元数据，远比整理后的轨迹“脏”。MessyMem 直接从这类交互记录中学习何时写入、何时检索和如何重新激活 episodic memory，使记忆成为执行闭环的一部分。
   - **实验与关注价值**：在多步机器人任务中比较无记忆、静态摘要和可学习记忆策略，关注跨回合复用经验与失败恢复。核心信号是机器人记忆正在从“保存日志”转向“决定哪些经历会改变下一次动作”。
   - **局限**：记忆污染、错误归因和检索延迟会放大长期执行风险；跨本体、跨环境和数周级持续运行的证据仍有限。

4. [Touch2Trace: Learning Contact-Rich Manipulation from Tactile Traces](https://arxiv.org/abs/2609.15976)

   - **问题与机制**：接触丰富操作中的关键状态常被视觉遮挡，单帧触觉也难以表达接触事件的时间结构。Touch2Trace 将连续触觉痕迹与动作过程对齐，用接触历史帮助策略判断滑移、卡住、接触变化和后续动作。
   - **实验与关注价值**：在接触操作任务上评估触觉序列表示、跨时间预测和策略控制，重点是触觉是否能在视觉不充分时提供可用的动作证据。它把触觉从附加传感器提升为可追踪的过程信号。
   - **局限**：触觉传感器的耐久、标定、材料迁移和跨手型泛化仍是部署瓶颈；任务成功率还需要与恢复成本、接触损伤和控制频率一起报告。

## 世界模型与控制接口

5. [WLA3: Action-Conditioned World Models for Long-Horizon Autonomous Manipulation](https://arxiv.org/abs/2609.15475)

   - **问题与机制**：长时操作需要预测动作后果，但纯视觉预测容易忽略接触、物体状态和任务阶段。WLA3 以动作条件世界模型连接观测、动作和未来状态，面向长时自主操作提供可用于规划或候选动作评估的 rollout。
   - **实验与关注价值**：在长时 manipulation 任务中比较动作条件预测、短视策略和不同规划接口，关注世界模型是否真正改善任务完成而非只提高视频相似度。方向上，它把世界模型的评价从“画面像不像”移到“是否能帮助下一步动作”。
   - **局限**：模型 rollout 的误差会随时域累积；真实接触、不可逆形变和未见物体仍可能使规划器过度相信想象结果。

6. [X-WBC: Cross-Embodiment Whole-Body Control via Shared Action Interfaces](https://arxiv.org/abs/2609.15454)

   - **问题与机制**：不同机器人具有不同自由度、关节布局和动力学，直接共享动作 token 会造成接口错配。X-WBC 学习跨本体的全身控制接口，把高层行为意图映射到各自可执行的身体控制空间。
   - **实验与关注价值**：在多种本体或模拟身体上评估共享接口、零样本迁移和少量适配，关注全身动作是否能在本体变化后保持语义一致。若成立，它为 VLA 的跨机器人扩展提供了比统一关节向量更稳健的边界。
   - **局限**：跨本体“语义等价”仍依赖动作范围、接触能力和任务定义；模拟迁移到真机时，动力学和安全约束不能由接口本身消除。

## 导航与空间记忆

7. [HarnessVLN: A Tool-Using Agent Harness for Long-Horizon Vision-Language Navigation](https://arxiv.org/abs/2609.15426)

   - **问题与机制**：长时视觉语言导航的失败往往来自状态丢失、子目标漂移、恢复不足，而不只是单步视觉理解。HarnessVLN 将导航 Agent 包装在带有子目标、工具调用、状态检查和失败恢复的 harness 中，把执行过程显式化。
   - **实验与关注价值**：在长时 VLN 任务上比较裸模型与 harness 化 Agent，分析子目标规划、地图/记忆使用和恢复策略对成功率与轨迹长度的影响。它与机器人系统的共同启示是：Agent 的运行时合同和恢复机制本身就是模型能力的一部分。
   - **局限**：工具和恢复策略可能针对 benchmark 过拟合；真实场景中的定位漂移、动态障碍和感知延迟仍需要闭环验证。

8. [P-POSEMEM: Rewritable Pose Memory for Open-World Semantic Mapping](https://arxiv.org/abs/2609.15322)

   - **问题与机制**：开放世界中对象类别、位置和状态会变化，静态语义地图容易保留过时事实。P-POSEMEM 维护可重写的位姿记忆，用新观测更新对象的空间状态，而不是只追加新的地图条目。
   - **实验与关注价值**：在跨时间、对象移动和语义地图查询场景中评估记忆更新、定位与检索，关注地图是否能表达“现在在哪里”以及“此前发生过什么”。这对长期自治、家庭机器人和移动操作都比一次性建图更直接。
   - **局限**：更新错误会造成历史覆盖或错误重定位；长期运行仍需处理对象身份、遮挡、传感器退化和不确定性校准。

## 趋势总结

- **安全从结果评价前移到动作接口**：视频世界模型做事前过滤，组合鲁棒性 benchmark 暴露复合感知失效，二者共同指向“预测和评测必须能约束执行”。
- **机器人记忆开始学习写入与恢复**：MessyMem 和 P-POSEMEM 分别处理经历记忆与空间事实，重点从存储容量转向何时更新、何时覆盖、如何核验。
- **世界模型的价值标准更接近控制闭环**：WLA3 将动作条件预测接到长时操作，触觉痕迹则补充视觉不可见的接触过程；下一步关键是误差校准和真实恢复成本。
- **Agent 运行时成为研究对象**：HarnessVLN 与 X-WBC 分别从导航 harness 和跨本体动作接口处理系统边界，具身基础模型正在从“一个策略”转向“模型、接口、记忆和恢复机制”的组合。
